如何查一条结果
experiment_index.json 的 runs 以 run_id 为主键，包含完整 configuration、
checkpoint 路径与 SHA256、train/test split 哈希、源码哈希数量及 best_metrics。
evidence/<run_id>/ 保存 manifest、best_metrics、status 和可用的独立审计。
manifest.source_sha256 给出逐文件源码版本。完整 epochs.jsonl 保存在论文工作区
交接包及索引指向的原归档中；仓库只提交小型元数据，权重保持外部归档。
参考协议与runner位于 protocols/，源码快照与归档哈希位于 sources/ 和
artifact_inventory.json。绝对路径用于本机定位，迁移时按归档名与哈希恢复。

复现历史实验
必须使用对应manifest的源码与runner、完整configuration、环境锁和相同数据划分。
NUAA固定协议为 Adagrad / lr0.05恒定 / batch8 / seed40 / 300epochs；
主实验为600epochs cosine，二者不能互换。IRSTD受控实验为256输入，不能与
论文主表历史512输入结果混用。threshold=0.1，四项指标来自同一最佳IoU权重。
Fa使用按连通域ID匹配后的未匹配区域面积；不要替换成旧面积相等判断实现。
固定协议runner命令格式：
python artifacts/run_nuaa_fixed005.py --mode run --matrix artifacts/nuaa_fixed005_matrix.json --job experts_multi_low
此命令要求在隔离目录恢复原 /root/autodl-tmp/moe_reproduction 布局、
code/experiment_runtime、data、artifacts 和锁定环境；不能直接在最终代码目录执行。
其他runner和matrix以各run归档为准；HF试验有独立起始包，不能套用同一源码。
